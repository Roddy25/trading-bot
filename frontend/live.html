How to go live, step by step

Nothing here executes on its own. Each step is explicit.

1. Run the backend bridge

Clone the project, then in server/ run npm install and npm start. It listens on localhost:8787 and holds your credentials. See server/README.md.

2. Connect your live account

Enter your MT5 login/server/password, or your Exness or Deriv API credentials. They are POSTed to your backend only and never touch this website.

3. Accept the risk gate

Tick every statement. Live order entry stays disabled until you do — the checkbox state is enforced before any order can be submitted.

4. Submit an order

Choose symbol, side, volume, order type and optional SL/TP, then submit. Your backend forwards it to the broker and returns the ticket.

5. Monitor and revoke

Positions and account figures refresh from the broker. Disconnect at any time, or stop the backend process to cut the connection immediately.

What this build cannot do

It cannot trade with credentials alone — the bridge must be running, and a real implementation needs broker-side API access, error handling, reconciliation and compliance in place.
